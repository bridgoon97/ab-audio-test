# A/B 音频主观测试工具

轻量级的 Windows 桌面程序（Python + PySide6 / Qt），用于音频 **双盲 A/B 对比听音打分**，
适合编解码器、降噪算法、音频处理链等的主观质量评价。

## 功能特性

- **双盲测试**：随机打乱样本顺序；每个样本随机交换 A / B，结果文件中记录真实对应关系（揭盲信息）
- **即时切换**：A / B 播放零延迟切换，支持无缝循环，便于反复对比
- **评分制**：每个样本按 1–5 分（很差 → 优秀）评分，可填备注；A、B 都打分后才能进入下一项
- **实时保存**：每完成一项立即写入 CSV，中途退出不丢已完成的数据
- **格式支持**：wav / flac / mp3 / ogg / aiff（mp3 需较新版 soundfile 支持）
- **可打包 exe**：一条命令打成单个 exe，无需安装 Python 即可分发

## 快速开始

使用 [uv](https://docs.astral.sh/uv/) 管理依赖（Windows / macOS / Linux 均可；
没有 Python 也没关系，uv 会自动准备）：

```bat
uv sync                rem 创建 .venv 并安装依赖（含 Python 本身，如缺失会自动下载）
uv run make_demo_audio.py   rem 可选：在 demo_audio/ 生成 3 对演示样本
uv run ab_test.py
```

运行后：选择音频文件夹 → 填写试听者 → 开始测试 → 依次播放 A/B 并打分。

## 样本命名规则

同一文件夹内，一对样本的两个文件以 `_A` / `_B` 结尾（也支持 `_1` / `_2`）：

```
audio/
├── guitar_A.wav      ├── guitar_1.wav
├── guitar_B.wav      或   ├── guitar_2.wav
├── vocal_A.wav            ├── vocal_1.wav
└── vocal_B.wav            └── vocal_2.wav
```

未按规则配对的文件会被忽略（界面上会提示数量）。

## 快捷键

| 键 | 功能 |
|----|------|
| `A` / `B` | 播放 A / B |
| `空格` / `Esc` | 停止 |
| `L` | 循环播放开关 |
| `回车` | 下一项（需 A、B 均已评分） |

## 结果文件

结果保存在程序目录的 `results/` 下，CSV 格式（UTF-8 BOM，Excel 可直接双击打开），
文件名形如 `20240101_120000_张三.csv`，字段：

| 字段 | 说明 |
|------|------|
| 时间 / 试听者 / 序号 / 样本 | 基本信息 |
| A=实际文件 / B=实际文件 | **揭盲信息**：本次实际作为 A、B 播放的原始文件名 |
| A评分 / B评分 | 1–5 |
| 备注 / 用时(秒) | 可选备注、该项耗时 |

## 打包为单个 exe

双击 `build_windows.bat`，或手动执行：

```bat
uv run pyinstaller --noconfirm --onefile --windowed --name ABTestAudio ab_test.py
```

生成 `dist\ABTestAudio.exe`，可拷贝到任意 Windows 机器直接运行
（结果保存在 exe 同目录的 `results/` 下）。

> 依赖声明在 `pyproject.toml`，锁定版本在 `uv.lock`（提交到 git 保证环境一致）；
> 添加依赖用 `uv add <包名>`，开发依赖用 `uv add --dev <包名>`。

## 听音测试建议

- 使用耳机、安静环境；各版本样本的**响度尽量一致**（响度差会主导判断）
- 每项建议听两三遍、A/B 来回切换后再打分，可用循环模式辅助
- 多人测试更可靠；汇总时对多名试听者的评分取均值，必要时做显著性检验
- 同一个文件不要在 A/B 中重复出现在多对里造成听感疲劳，单轮样本数建议 ≤ 15 对

## 常见问题

- **没有声音**：检查设置页“输出设备”选择是否正确、系统音量是否正常
- **mp3 读取失败**：需要 soundfile ≥ 0.12（libsndfile ≥ 1.1）；建议优先使用 wav / flac- **样本采样率 / 声道不同**：允许，播放器会自动适配（切换瞬间会重建输出流，可能有微小间隙）
